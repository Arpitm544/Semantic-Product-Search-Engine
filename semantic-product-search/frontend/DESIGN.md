# Landing page foundation

This frontend is an original, standalone product-discovery concept. It uses a wide editorial hero, calm colors, serif display type, a responsive navigation, and curated product previews from a local catalog snapshot.

The artwork in `public/images/` was generated for this project. The catalog cards use illustrative artwork because the product records do not include product photos. Prices are displayed in INR.

The page is built with Next.js App Router, React, plain CSS, and original SVG icons. It does not connect to backend APIs or execute search models. Keyboard focus and reduced-motion preferences are supported.
